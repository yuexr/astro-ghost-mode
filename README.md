# Ghost Mode

Use console commands to toggle visibility of player astronaut, backpack, and terrain tool.

> [!WARNING]
> This mod is unreleased; it has not been formally tested or optimized to be stable. There may be compatibility issues or bugs. Developed for personal-use.

- Can be toggled individually or together.
- Does not change behaviour or functionality of any other game function.
- Backpack displays normally when expanded, even if hidden.
- Related actors are also hidden (e.g. attached items).

## Console Command Controls

Requires UE4SS ConsoleCommandsMod.

Available commands:
```
ghost <show/hide>
ghost body <show/hide>
ghost backpack <show/hide>
ghost terraintool <show/hide>
```

Case insensitive.
`<on/off>` works as alias for `<show/hide>`.
`bp` works as `backpack`, and `tt` works as `terraintool`.
